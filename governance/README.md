# Governance

The `governance/` directory contains the example content of the `ThreatCatalog`, `CapabilitiesCatalog`, and `ControlCatalog` for the CNCF CloudNative PostGreSQL project. The content has been migrated to Gemara v1.0.0 using the Gemara MCP Server. The original `threat-assessment.yaml` was created during the [2026 Security Slam](https://github.com/cloudnative-pg/cloudnative-pg/pull/10304) and has since been migrated using the Gemara MCP Server.
